# Java Fundamentals - Learning Roadmap

This document outlines the learning path for Java Fundamentals (Section 1).

---

##  Learning Goals

By the end of this section, you should be able to:
- Write and run Java programs from command line
- Understand primitive and reference data types
- Use Scanner for user input (and handle buffer issues)
- Work with operators and control flow
- Create and use methods
- Work with arrays and ArrayList

---

##  Topics Checklist

### Introduction to Java
- [x] What is Java? JVM, JRE, and JDK
- [x] "Write Once, Run Anywhere" philosophy
- [x] Setting up IntelliJ IDEA

### Your First Program
- [x] The `main` method: `public static void main(String[] args)`
- [x] Using `System.out.println()`
- [x] Compiling with `javac` and running with `java`

### Variables and Data Types
- [x] Primitive Types: `int`, `double`, `char`, `boolean`, `byte`, `short`, `long`, `float`
- [x] Reference Types: `String`
- [x] Declaring and initializing variables
- [x] Scanner input methods: `nextLine()`, `nextInt()`, `nextDouble()`, `next()`
- [x] Scanner buffer problem and solution

### Operators
- [x] Arithmetic: `+`, `-`, `*`, `/`, `%`
- [x] Relational: `==`, `!=`, `>`, `<`, `>=`, `<=`
- [x] Logical: `&&`, `||`, `!`
- [x] Assignment: `=`, `+=`, `-=`, etc.
- [x] Unary: `++`, `--`
- [x] Ternary: `? :`
- [x] Bitwise: `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`

### Control Flow
- [x] `if`, `else if`, `else`
- [x] `switch` statements
- [x] `for` loop
- [x] `while` loop
- [x] `do-while` loop
- [x] `break` and `continue`

### Arrays
- [x] Declaring and initializing arrays
- [x] Iterating over arrays
- [x] Multi-dimensional arrays
- [x] ArrayList basics

### Methods
- [x] Defining and calling methods
- [x] Parameters and return values
- [x] Method overloading
- [x] Recursion

---

##  Exercises

1.  Write a program that converts temperature from Celsius to Fahrenheit
2.  Create a simple calculator for basic arithmetic operations
3.  Write a program to find the largest number in an array
4.  Create a method that checks if a number is prime
5.  Swap two variables without using a third variable
