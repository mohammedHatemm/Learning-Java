##  Topics Covered

### 1. Variables and Data Types (`variable/`)
- **Primitive Types:** `int`, `double`, `char`, `boolean`, `byte`, `short`, `long`, `float`
- **Reference Types:** `String`
- Scanner for user input
- Scanner buffer issue after `nextInt()`/`nextDouble()`
- Variable swapping using arithmetic operators

### 2. Operators (`operation/`)
- Arithmetic: `+`, `-`, `*`, `/`, `%`
- Unary: `++`, `--`, `!`
- Assignment: `=`, `+=`, `-=`
- Relational: `==`, `!=`, `>`, `<`, `>=`, `<=`
- Logical: `&&`, `||`, `!`
- Ternary: `? :`
- Bitwise: `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`

### 3. Type Casting (`TypeCasting/`)
- Widening casting (implicit): `int` → `double`
- Narrowing casting (explicit): `double` → `int`

### 4. Conditional Statements (`ConditionStatment/`)
- `if`, `else if`, `else`
- `switch` statements
- Nested conditions

### 5. Strings (`String/`)
- String creation and manipulation
- String pool concept (`==` vs `.equals()`)
- Methods: `length()`, `charAt()`, `substring()`, `toUpperCase()`, `toLowerCase()`
- `StringBuilder` for mutable strings

### 6. Printf Formatting (`PrintF/`)
- Format specifiers: `%s`, `%d`, `%c`, `%f`, `%b`
- Precision formatting: `%.2f`

### 7. Loops (`loop/`)
- `for` loop
- `while` loop
- `do-while` loop
- Enhanced for-each loop
- `break` and `continue`

### 8. Methods (`method/`)
- Method definition and parameters
- Return types
- Method overloading
- Recursion
- Variable arguments (varargs)

### 9. Arrays (`Array/`)
- Array declaration and initialization
- Iterating with loops
- `Arrays.toString()` and `Arrays.sort()`
- 2D arrays
- `ArrayList`
